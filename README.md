# Food Waste Prediction Using Machine Learning

## Overview
This project explores the use of machine learning and data mining techniques to analyze and predict food waste in food-service environments.

## Objectives
- Explore operational and historical factors associated with food waste.
- Compare machine learning regression models.
- Investigate operational patterns using clustering and association-rule mining.
- Evaluate models using time-aware validation.
- Explore feature importance using SHAP explainability.

## Methods
- Data preprocessing and exploratory data analysis
- Linear Regression
- Random Forest Regression
- Gradient Boosting
- XGBoost
- K-Means clustering
- Apriori association-rule mining
- SHAP explainability

## Project Files
- `code.ipynb` — Project notebook
- `paper/` — Research paper draft, when added

## Results
The notebook contains model evaluation results and analytical visualizations. Results should be interpreted in the context of the dataset and validation procedure.

## Limitations
The dataset's provenance and results need further verification. Predictions do not establish that food waste has been reduced in a real-world setting.
